# Copper Flint and Steel

A flint and steel made from copper. It works everywhere the vanilla one does (fire, nether portals,
candles, campfires, TNT, creepers, dispensers) but lasts **40 uses** instead of 64.

Fabric mod for Minecraft 26.3 (Java 25, Mojang names). Requires Fabric API only. Singleplayer and server.

- Recipe (shapeless): 1 copper ingot + 1 flint.
- Creative tab: Tools & Utilities, right after the vanilla flint and steel.
- Enchantable with Unbreaking and Mending; repair on an anvil with copper ingots.

## Development

Build and test: `.\gradlew.bat build`. Full check (build, unit tests, in-game client gametest):
`.\scripts\verify.ps1`.
